اقرأ الـMarkdown كما ينبغي أن يُقرأRead Markdown the way it should be read

متن يفتح ملف Markdown ويعرضه نصًا عربيًا حقيقيًا من اليمين إلى اليسار — يحسم اتجاه كل فقرة وحدها، فيبقى المستند عربيًا وإن بدأ سطرٌ بكلمة لاتينية، ويبقى الكود والإنجليزية على اتجاههما داخله. لا يحرّر ملفاتك، ولا يرفعها، ولا يطلب حسابًا. Matn opens a Markdown file and renders it as genuine right-to-left Arabic — it settles the direction of each block on its own, so an Arabic document stays Arabic even when a line opens with a Latin word, while code and English keep their own direction inside it. It never edits your files, never uploads them, and never asks for an account.

جرّب في المتصفحTry it in the browser الشيفرة على GitHubSource on GitHub
npm install -g Ajarallah/matn

يحتاج Node.js 18 فأحدث، ولا شيء غيره — متن بلا تبعيات تشغيل. النسخة في المتصفح تعمل كذلك دون تثبيت، لكن نسخة سطر الأوامر هي التي تقرأ مجلداتك. Needs Node.js 18 or newer and nothing else — Matn has no runtime dependencies. The browser build works without installing anything, but the CLI is what reads your folders.

الاتجاه يصحّ من تلقاء نفسهDirection settles itself

لا زرّ اتجاه ولا إعداد. متن يقيس كل كتلة ويصوّت على اتجاهها، فالفقرة العربية عربية، وكتلة الكود لاتينية، في المستند نفسه.No direction toggle, no setting. Matn measures each block and votes on its direction, so an Arabic paragraph is Arabic and a code block is Latin, in the same document.

أربع سمات وأربعة أنماط قراءةFour themes, four reading modes

فاتح وسيبيا وداكن وليلي، وخطوط عربية مدمجة، وعرض العمود والتباعد والمحاذاة بين يديك — واختصارات جاهزة للمقالة والبحث والتوثيق والنص الطويل.Light, sepia, dark and night, embedded Arabic fonts, and column width, leading and alignment under your hand — with ready presets for articles, papers, docs and long reads.

ملفاتك تبقى ملفاتكYour files stay yours

متن قارئ لا محرّر: يفتح للقراءة فقط، ويعمل على 127.0.0.1 دون اتصال، ولا يخرج من المجلد الذي فتحته. لا حساب، ولا مزامنة، ولا تتبّع.Matn reads, it does not edit: read-only, served on 127.0.0.1 with no network, and confined to the folder you opened. No account, no sync, no telemetry.

التثبيتInstall

تشغيل مرة واحدة بلا تثبيت.Run once, install nothing.
