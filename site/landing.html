قارئ Markdown محلي للعربيةA local Markdown reader for Arabic

اقرأ الـMarkdown كما ينبغي أن يُقرأRead Markdown the way it should be read

يفتح ملفاتك كما هي ويعرضها نصًا عربيًا من اليمين إلى اليسار. لا يحرّرها، ولا يرفعها، ولا يطلب حسابًا. Opens your files as they are, right to left. Never edits them, never uploads them, never asks for an account.

ثلاثة أشياء يصعب أن تجدها مجتمعةThree things that are hard to find together

الاتجاه يصحّ من تلقاء نفسهDirection settles itself

لا زرّ اتجاه ولا إعداد. متن يقيس كل كتلة ويصوّت على اتجاهها، فالفقرة العربية تبقى عربية وإن بدأت بكلمة لاتينية، وكتلة الشيفرة تبقى لاتينية، في المستند نفسه. هذه أكثر شكوى مفتوحة في قرّاء Markdown الأخرى.No direction toggle, no setting. Matn measures each block and votes on its direction, so an Arabic paragraph stays Arabic even when it opens with a Latin word, and a code block stays Latin, in the same document. This is the longest-standing open complaint across other Markdown readers.

خطوط عربية مدمجة، وعرض العمود والتباعد والمحاذاة بين يديك، واختصارات جاهزة للمقالة والبحث والتوثيق والنص الطويل.Embedded Arabic fonts, with column width, leading and alignment under your hand, plus ready presets for articles, papers, docs and long reads.

ملفاتك تبقى ملفاتكYour files stay yours

قارئ لا محرّر: يفتح للقراءة فقط، ويعمل على 127.0.0.1 دون اتصال، ولا يخرج من المجلد الذي فتحته. لا حساب، ولا مزامنة، ولا تتبّع.A reader, not an editor: read-only, served on 127.0.0.1 with no network, confined to the folder you opened. No account, no sync, no telemetry.

التثبيتInstall

أمر واحد، ثم افتح أي ملفOne command, then open any file

يحتاج Node.js 18 فأحدث، ولا شيء غيره. متن بلا تبعيات تشغيل.Needs Node.js 18 or newer and nothing else. Matn has no runtime dependencies.

npm install -g Ajarallah/matn

يُثبّت من GitHub مباشرة. متن ليس منشورًا على npm بعد، فلا تكتب npm i -g matn.Installs straight from GitHub. Matn is not published on npm yet, so npm i -g matn will not work.

npx github:Ajarallah/matn README.md

تشغيل مرة واحدة بلا تثبيت.Run once, install nothing.

git clone https://github.com/Ajarallah/matn.git && cd matn && npm link

بلا تبعيات، فلا حاجة إلى npm install.No dependencies, so no npm install needed.

bash scripts/install-macos.sh --default

يبني Matn.app في ~/Applications ويسجّله لفتح ملفات Markdown بالنقر المزدوج. الخيار --default يحتاج duti.Builds Matn.app in ~/Applications and registers it to open Markdown on double-click. The --default flag needs duti.
