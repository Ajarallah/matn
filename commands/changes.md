---
description: See what the user changed in a file since you last read it
argument-hint: "<file>"
allowed-tools: Bash(matn:*)
---
Run `matn changes $ARGUMENTS --mark` with the Bash tool. It lists the blocks added, edited and removed since you last marked the file, then records it as read. Treat the edits as the user's instructions for this file and take them into account in what you do next.
