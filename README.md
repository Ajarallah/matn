## لماذا متن؟

تتعثر العربية في كثير من المحررات والطرفيات: ينعكس الاتجاه، وتتداخل الكلمات الإنجليزية، وقد ينقلب العنوان كله لأنه يبدأ بكلمة لاتينية. يعرض متن ملف `.md` في المتصفح كمستند عربي صحيح ومريح للقراءة الطويلة.

| عربية صحيحة | محلي وخاص | قارئ متكامل |
|---|---|---|
| يحدد لغة المستند الغالبة، فيحفظ اتجاه العربية واتجاه المقاطع اللاتينية داخل السطر نفسه. | يعمل دون اتصال، ويرتبط محليًا بـ`127.0.0.1`، ولا يرسل ملفاتك إلى أي خدمة. | يضيف التنقل والبحث والسمات والتعليقات ووضع الكتاب والتصدير، من دون تغيير ملفات Markdown. |

## البدء السريع

ثبّت الحزمة وافتح أي ملف:

```bash
npm install -g @ajarallah/matn
matn README.md
```

أو جرّبه بلا تثبيت:

```bash
npx @ajarallah/matn README.md
```

يحتاج Node.js 18 فأحدث. لا يحتاج إلى تبعيات تشغيل أو خطوة بناء.

## ما الذي يقدمه؟

- **قراءة عربية مضبوطة:** اتجاه ثنائي صحيح، وأربع سمات، وخطوط عربية مدمجة، وتحكم في الخط والحجم والتباعد والعرض والمحاذاة.
- **محتوى غني يعمل دون اتصال:** تلوين للكود، ومعادلات KaTeX، ومخططات Mermaid، وحواشٍ، وتنبيهات GFM، وروابط ويكي.
- **تنقل يحفظ موضعك:** خريطة للمستند، وبحث، وشجرة ملفات، وذاكرة قراءة، ومفضلة، و«أكمل لاحقًا».
- **مساحات قراءة كاملة:** افتح مجلدًا أو استخدم `SUMMARY.md` في وضع الكتاب، مع السابق والتالي والتقدم الإجمالي.
- **تعليقات لا تمس المصدر:** ميّز النص، وأضف ملاحظات، واحفظ مقتطفاتك من دون تعديل ملف Markdown.
- **إخراج جاهز للمشاركة:** صدّر PDF أو HTML مستقلًا أو Word أو EPUB 3 أو Markdown، واطبع بتنسيق نظيف.

## الاستعمال

```bash
matn <file.md>        # افتح ملفًا واحدًا
matn ./docs           # تصفّح مجلدًا من شجرة الملفات
matn                  # افتح المجلد الحالي
command | matn -      # اقرأ Markdown من stdin
matn PLAN.md -p 5000  # اختر منفذًا
```

الخيارات: `-p, --port` · `--host` · `--no-open` · `--editor <executable>` · `--allow-file-actions` · `--stdin-name <name>` · `-h, --help` · `-v, --version`.

يفتح متن المتصفح تلقائيًا ويعيد استخدام النسخة المفتوحة. استخدم `/` للبحث، و`</>` للتبديل بين العرض المصيّر والمصدر والتقسيم، و**حفظ** للتصدير.

<details>
<summary><strong>اجعل متن القارئ التلقائي لملفات Markdown</strong></summary>

**macOS**

```bash
bash "$(npm root -g)/@ajarallah/matn/scripts/install-macos.sh" --default
```

ينشئ الأمر تطبيق Finder صغيرًا ويسجل صيغ Markdown، ولا يحتاج إلى Homebrew أو `duti`. للتراجع:

```bash
bash "$(npm root -g)/@ajarallah/matn/scripts/install-macos.sh" --uninstall
```

**Linux:** شغّل `bash scripts/install-linux.sh --default` لإضافة مدخل `.desktop` وربط `text/markdown` بمتن.

**Windows:** يعمل `matn file.md` من أي طرفية. اربط `.md` من **Open with → Choose another app**.

</details>

## كيف يعمل؟

يشغل متن خادم HTTP محليًا صغيرًا من دون تبعيات تشغيل. يعرض Markdown عبر [marked](https://github.com/markedjs/marked)، ويضبط اتجاه كل كتلة بحسب لغة المستند الغالبة، ويلوّن الكود عبر [highlight.js](https://github.com/highlightjs/highlight.js)، ويعرض المعادلات عبر [KaTeX](https://katex.org) والمخططات عبر [Mermaid](https://mermaid.js.org). يرسل التحديثات الفورية عبر SSE، وتبقى المكتبات والخطوط مدمجة للعمل دون اتصال.

## الأمان

يرتبط متن تلقائيًا بـ`127.0.0.1`، ولا يعرض الملفات إلا من الملف أو المجلد الذي فتحته. يعزل HTML الخام ويمنع الروابط غير الآمنة مثل `javascript:`. لا تستخدم `--host 0.0.0.0` إلا إذا أردت إتاحة القارئ لأجهزة شبكتك. اقرأ [سياسة الأمان](./SECURITY.md).
