# متن · Matn

**ماركداون عربي كما ينبغي أن يُقرأ.**

## لماذا متن

تسيء كثير من المحرّرات والطرفيات عرض ماركداون العربي: لا تضبط الاتجاهين، وتقطّع
الحروف، وتخلط أسطر العربية والإنجليزية حتى تنكسر. وقد تقلب العنوان كله إلى اليسار
لمجرد أنه يبدأ بكلمة إنجليزية. يعرض **متن** ملف `.md` في المتصفح مستندًا عربيًا صحيحًا من اليمين إلى اليسار،
مع بقاء الكود والإنجليزية داخله من اليسار إلى اليمين، ضمن تجربة قراءة مريحة للنصوص الطويلة.

## المزايا

**القراءة**

- 🪶 **اتجاه عربي صحيح:** يتبع المستند لغته الغالبة، فيبقى الملف العربي من اليمين إلى اليسار حتى لو بدأ سطر أو عنوان بكلمة إنجليزية، وتبقى الكلمات الإنجليزية داخل السطر من اليسار إلى اليمين.
- 🎨 **أربع سمات:** فاتح، وسيبيا، وداكن، وليلي (أسود كامل)؛ ويتبع نظامك تلقائيًا.
- 🔤 **خطوط عربية مدمجة:** النظام، ونوتو نسخ، وأميري، وIBM Plex، وتجوّل (كلها برخصة SIL OFL، مدمجة وتعمل دون اتصال)، وخط ثمانية (Display وText) اختياري.
- 🔧 **تحكّم بالقراءة:** الخط، والحجم، وتباعد الأسطر، وعرض العمود، ومحاذاة النص (من اليمين أو ضبط الأسطر)؛ وكل اختيار محفوظ.
- 🌍 **واجهة بلغتين:** بدّل الواجهة كاملة بين العربية والإنجليزية.

**المحتوى**

- 🌈 **تلوين الكود** حسب السمة (highlight.js).
- 🧮 **معادلات:** `$…$` داخل السطر و`$$…$$` مستقلة، عبر KaTeX ودون اتصال.
- 📊 **مخططات Mermaid:** تظهر داخل النص وحسب السمة، ويمكن تكبيرها عند الإشارة.
- 💬 **صناديق تنبيه GFM:** تظهر `> [!NOTE]` و`[!TIP]` و`[!WARNING]` بتنسيق يميّز كل نوع.
- 🔗 **روابط ويكي وملفات عاملة:** `[[صفحة]]` والروابط النسبية والأسماء البديلة، مع معاينة وروابط واردة.
- ◇ **سلامة المستند:** تقرير محلي للروابط والصور والعناوين المفقودة، دون فحص الشبكة أو مغادرة مجلد القراءة.
- 📝 **حواشٍ**، و**بطاقة للبيانات الوصفية (YAML)**، وقوائم مهام، وجداول، واقتباسات.
- 🖼️ **تكبير عند الإشارة:** كبّر المخططات والصور حول موضع المؤشّر.

**التنقّل والملفات**

- 🧭 **خريطة مستند مصغّرة** تتبع العنوان الحالي وتفتح قائمة عناوين كاملة باللمس أو لوحة المفاتيح.
- 🧠 **ذاكرة قراءة** تستعيد الملف والقسم والموضع، مع مفضلة و«أكمل لاحقًا» وتعليقات لا تغيّر Markdown.
- 🗑️ **نقل آمن إلى سلة النظام:** اختياري، مع تحذير لملفات Git والروابط الواردة، ودون حذف نهائي.
- 🗂️ **شجرة ملفات:** افتح مجلدًا لتتصفّح أدلّته المتداخلة والقابلة للطي.
- 📖 **وضع الكتاب:** يقرأ `SUMMARY.md` لترتيب الفصول، مع السابق والتالي والتقدم الإجمالي، دون بناء الملفات أو تعديلها.
- 🔎 **بحث داخل المستند:** استخدم `/` للبحث والتنقّل بين النتائج.
- ♻️ **تحديث فوري:** حرّر الملف بأي محرّر، فتتحدّث الصفحة عند الحفظ.
- 🐘 **ملفات كبيرة بلا تجميد:** تُصيّر الملفات الأكبر من 2 MB في Worker وتُحمّل تدريجيًا مع بقاء الواجهة مستجيبة.
- 🖱️ **سحب وإفلات** لأي `.md` على النافذة.

**الإخراج**

- 📤 **تصدير:** PDF أو HTML مستقل أو Word‏ (`.docx`) أو EPUB 3 (ترتيب صفحات من اليمين) أو ماركداون.
- 🖨️ **طباعة** بتنسيق نظيف.

**الأساس**

- 📦 **بلا تبعيات تشغيل:** Node فقط مع ملفات مدمجة؛ يعمل دون اتصال ولا يرسل أي بيانات.
- 🔒 **محدود النطاق:** يرتبط بـ`127.0.0.1`، ولا يعرض إلا من المجلد الذي فتحته، ويعزل HTML الخام، ويمنع الروابط غير الآمنة.
- 📄 **صيغ Markdown الشائعة:** يفتح `.md` و`.markdown` و`.mdown` و`.mkdn` و`.mkd`
  و`.mdwn` و`.mdtxt` و`.mdtext` و`.rmd` و`.qmd`.

## التثبيت

```bash
npm install -g @ajarallah/matn
matn README.md
```

> يحتاج Node.js إصدار 18 فأحدث. لا تبعيات تشغيل ولا خطوة بناء.

**تشغيل بلا تثبيت:**
```bash
npx @ajarallah/matn README.md
```

**من المصدر (للتطوير):**
```bash
git clone https://github.com/Ajarallah/matn.git
cd matn && npm link
```

> الاسم العام `matn` على npm تحجزه حزمة أخرى لا علاقة لها بالمشروع؛ لذلك الحزمة باسم
> `@ajarallah/matn`، والأمر التنفيذي يبقى `matn`.

**إزالة التثبيت:**
```bash
bash "$(npm root -g)/@ajarallah/matn/scripts/install-macos.sh" --uninstall   # على macOS
npm rm -g @ajarallah/matn
```

## الاستعمال

```bash
matn <file.md>        # فتح ملف واحد
matn ./docs           # تصفّح مجلد (شجرة ملفات جانبية)
matn                  # فتح المجلد الحالي
command | matn -      # قراءة Markdown من stdin في جلسة مؤقتة
matn PLAN.md -p 5000  # منفذ مختار
```

الخيارات: `-p, --port` · `--host` · `--no-open` · `--editor <executable>` · `--allow-file-actions` · `--stdin-name <name>` · `-h, --help` · `-v, --version`.

يفتح متن المتصفح تلقائيًا ويعيد استخدام النسخة المفتوحة، فـ`matn a.md` ثم `matn b.md` يفتحان في النافذة نفسها.

### داخل المتصفح

- افتح **⚙** لضبط نمط القراءة واللغة والسمة والخط والحجم والتباعد والعرض والمحاذاة؛ وكلها محفوظة.
- **حدّد نصًا مرة واحدة** لتظهر أدوات التمييز وإضافة الملاحظة وحفظ المقتطف في المفضلة ونسخه بصيغة غنية تحافظ على RTL والبنية، مع نص احتياطي ورابط المصدر.
- **أشر إلى خط في خريطة المستند** لمعاينة عنوان القسم، واختر الخط للانتقال إليه، أو افتح قائمة العناوين.
- **بدّل بين العرض المصيّر والمصدر والتقسيم** من زر `</>`؛ زر `¶` بجانب العنوان يصل إلى سطر Markdown المقابل.
- **اسحب** أي `.md` إلى النافذة لفتحه.
- **حفظ ▾** يصدّر PDF أو HTML أو Word أو EPUB أو ماركداون، و**🖨️** للطباعة.
- استخدم **/** للبحث. المفاتيح: `+` أو `−` للحجم · `g` أو `G` للأعلى أو الأسفل · `Esc` لإغلاق اللوحة.

## فتح `.md` بنقرة مزدوجة

**macOS:** اجعل متن القارئ التلقائي لماركداون بخطوة واحدة:

```bash
bash "$(npm root -g)/@ajarallah/matn/scripts/install-macos.sh" --default
```

ومن مستودع مستنسخ: `bash scripts/install-macos.sh --default`.

يبني تطبيق Finder صغيرًا، ويسجّل الصيغ العشر كلها، ويطالب بنوع Markdown عبر
LaunchServices، دون حاجة إلى Homebrew أو `duti`. وإن تعذّر ذلك أرشدك إلى
**Get Info ← Open with ← Change All**. وللتراجع: `--uninstall` ينقل التطبيق إلى سلة
النظام ويعيد `.md` إلى تطبيقك السابق.

**Linux:** يضيف الأمر `bash scripts/install-linux.sh --default` مدخل `.desktop` ويجعل متن معالج `text/markdown`.
**Windows:** يعمل الأمر `matn file.md` من أي طرفية؛ واربط `.md` من
*Open with ← Choose another app* بالإشارة إلى `matn`.

## كيف يعمل

متن خادم HTTP محلي صغير (`src/server.mjs`، بلا تبعيات). يعرض الماركداون عبر
[marked](https://github.com/markedjs/marked)، ويعطي كل كتلة نص اتجاه المستند الغالب لضبط
الاتجاهين، ويلوّن الكود عبر [highlight.js](https://github.com/highlightjs/highlight.js)،
ويعرض المعادلات عبر [KaTeX](https://katex.org) والمخططات عبر [Mermaid](https://mermaid.js.org)
(كلاهما يُحمّل عند الحاجة)، ويحدّث الصفحة فوريًا عبر SSE. الخطوط والمكتبات مدمجة، فيعمل دون
اتصال ولا يرسل أي بيانات.

## الأمان

يرتبط متن تلقائيًا بـ`127.0.0.1`، ولا يعرض ملفات ماركداون والصور المشار إليها إلا من الملف
أو المجلد الذي فتحته. ويعزل HTML الخام داخل الماركداون، ويمنع الروابط غير الآمنة مثل
`javascript:`. تجنّب `--host 0.0.0.0` إلا إذا أردت عمدًا إتاحة القارئ لأجهزة أخرى على شبكتك.
راجع [SECURITY.md](./SECURITY.md).
